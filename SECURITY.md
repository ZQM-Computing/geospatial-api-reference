## Security Policy

### Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Email <zqmcomputing@gmail.com> with a description of the vulnerability, steps to reproduce, and any relevant proof-of-concept.
3. We will acknowledge receipt within 48 hours and provide a timeline for a fix.

### Supported Versions

| Version | Supported |
|---------|-----------|
| Latest  | Yes       |

### Scope

This is a reference/cookbook repository. Security reports should focus on:
- Vulnerable dependencies
- Hardcoded secrets in example code
- Insecure patterns demonstrated in examples

### Out of Scope

- Issues in third-party dependencies (report upstream)
- Theoretical attacks without a working proof-of-concept
